Kernox Linux Preview Bundle
============================

This is a small, inspectable launching-soon preview bundle for Kernox.
It is not the finished desktop app and it does not install services,
timers, or system packages.

Run the terminal preview:

  ./kernox-preview.sh

Kernox is local-first Linux automation: define a task once, then enable it
when you want it to run. Everything stays on this machine.
